# Portofolio Arkanul Adelis

Next.js (Pages Router, folder `src`) + Material UI + lucide-react.

## Menjalankan
```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Mengubah isi
Semua teks, link, gambar, proyek, layanan, FAQ ada di **`src/data/portfolio.js`**.
Cari tanda `[ ... ]` lalu ganti dengan data asli Anda. Warna & font ada di `src/theme.js`.
Gambar memakai Unsplash sementara; ganti dengan gambar sendiri (taruh di folder `public/`, lalu isi `/nama-file.jpg`).
